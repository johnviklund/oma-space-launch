# MEMORY — index

One line per page in `memory/<slug>.md`: `- [<slug>](memory/<slug>.md) — <one-line claim> ·
occurrences N · <last confirmed>`. Only durable patterns, gotchas, and decisions worth recalling
across runs belong here — not task state, not git history (git is authoritative for that), not
anything already in `PRODUCT.md`/`DESIGN.md`/`AGENTS.md`.

A repeat of an existing claim bumps that page's `Occurrences` and `Last confirmed` rather than
adding a new line. `Occurrences: 3` is the signal to consider promoting the pattern into a skill.
